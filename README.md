**HabitsTrackerApp**  
Простое веб-приложение на **React + Vite** для отслеживания привычек.  
   
 Пользователь может добавлять привычки, отмечать их выполнение и удалять. Все данные сохраняются локально через localStorage браузера.

**Возможности**  
- Просмотр списка привычек.  
- Добавление новой привычки через ввод названия.  
- Отметка привычки как выполненной (клик по элементу).  
- Удаление привычки (правый клик мыши или кнопка удаления).  
- Локальное хранение данных через localStorage — привычки сохраняются между запусками.

**Установка и запуск**  
**1. Установить Node.js**  
- Node.js версии 18+ (рекомендуется LTS): [https://nodejs.org/](https://nodejs.org/ "https://nodejs.org/")  
Проверка:  
node -v  
 npm -v  
   
**2. Установить зависимости проекта**  
npm install  
   
**3. Запустить проект в браузере**  
npm run dev  
   
Команда соберёт проект и откроет его в браузере по адресу вида http://localhost:5173.
